# Caelestis Draft Instruments

This directory is reserved for developmental instruments that are not part of the operative corpus.

Drafts are:

- non-operative and not source-authoritative;
- excluded from current Charter, Constitution, global governance and canonical-code registries;
- ineligible to assert conformance or binding authority;
- retained for review, research, policy development or possible future adoption;
- promoted only through an explicit reviewed adoption amendment.

The `PLATINUM` designation is reserved for adopted or active governed instruments. Draft filenames in this directory therefore omit that designation.

Draft content may cite operative instruments for context. An operative instrument MUST NOT depend on a draft for a mandatory definition, duty, classification, procedure or authority rule.

No draft instrument is retained following the standards-normalisation stabilisation review. The disposition and preservation rationale for each retired proposal is recorded in `.github/Reviews/STANDARDS-NORMALISATION-STABILISATION-AND-REMAINING-WORK-REGISTER.md`; Git history remains the provenance record for removed draft text.
